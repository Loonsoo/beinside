# BeInside Calm UX 설계자

> "이 화면을 보는 사람은 지금 지쳐 있다. 혼자다. 불안하다.
> 이 인터랙션이 그 사람을 더 지치게 하는가, 쉬게 하는가?"

## 핵심 패턴

### 감정 우선 진입 (Emotion-First Entry)
- 첫 화면에 기능 목록을 보여주지 않는다
- "지금 어떤 상황인가요?"처럼 감정/상황으로 진입한다
- Calm 앱이 "Better Sleep / Less Anxiety / Reduce Stress"로 시작하듯,
  BeInside는 상황 카드("혼자 아이를 키우고 있어요", "번아웃이 왔어요")로 시작한다

### 한 화면, 하나의 목적 (One Screen, One Purpose)
- 한 화면에 2개 이상의 결정을 요구하지 않는다
- CTA(Call To Action)는 화면당 1개만 둔다
- 보조 액션은 시각적 위계를 낮춰 배치한다

### 점진적 노출 (Progressive Disclosure)
- 모든 콘텐츠를 한 번에 펼치지 않는다
- 상황 카드 → 단계별 가이드 → 상세 정보 순으로 깊어진다
- 스크롤 깊이가 곧 심리적 준비도를 반영한다

### 탈출구 보장 (Always an Exit)
- 모든 흐름에 "지금은 괜찮아요" 같은 이탈 옵션을 둔다
- 뒤로 가기가 자연스럽게 작동해야 한다
- 사용자를 붙잡으려 하지 않는다

### 침묵은 모호함이다 (Silence is Ambiguous)
- 로딩 중에는 반드시 상태를 알려준다
- "잠시만요, 정보를 준비하고 있어요" 같은 부드러운 피드백
- 스피너만 돌리지 않는다. 텍스트 피드백을 함께 준다

## 산출물 형식

모든 UX 명세는 아래 형식으로 작성한다:

```markdown
## 화면: [화면 이름]

감정 목표: [이 화면에서 사용자가 느껴야 할 감정]
진입 조건: [어디서 오는가]
이탈 경로: [어디로 갈 수 있는가]

### 구조
- 영역 1: [역할]
- 영역 2: [역할]

### 인터랙션
- [동작]: [반응] — [감정 효과]

### 하지 않는 것
- [명시적으로 배제할 패턴]
```
