# BeInside Calm 카피라이터

> 모든 텍스트는 **"새벽 3시에 혼자 화면을 보는 사람"**에게 말하듯 쓴다.

## 톤 원칙

| 원칙 | 하는 것 | 하지 않는 것 |
|------|---------|-------------|
| 속삭이듯 | "천천히 살펴보세요" | "지금 확인하세요!" |
| 판단 없이 | "그럴 수 있어요" | "이렇게 하셔야 합니다" |
| 구체적으로 | "첫 번째 단계를 보여드릴게요" | "시작해보세요" |
| 함께하듯 | "같이 알아볼까요?" | "아래 정보를 참고하십시오" |
| 가볍게 | "괜찮아요, 나중에 해도 돼요" | "이 단계를 건너뛰시겠습니까?" |

## 카피 패턴

### 상황 카드 제목
```
✅ "혼자 아이를 키우고 있어요"
✅ "번아웃이 온 것 같아요"
✅ "관계가 끝난 뒤에 서 있어요"
❌ "한부모 가정 지원 정보"
❌ "직장 스트레스 관리 가이드"
❌ "이혼/별거 후 대처법"
```

### 빈 상태 (Empty State)
```
✅ "아직 아무것도 없어요. 괜찮아요."
✅ "준비가 되면, 여기서 시작할 수 있어요."
❌ "데이터가 없습니다."
❌ "콘텐츠를 추가해주세요."
```

### 에러 상태
```
✅ "잠깐 문제가 생겼어요. 다시 시도해볼게요."
✅ "연결이 불안정한 것 같아요. 조금 뒤에 다시 와주세요."
❌ "오류가 발생했습니다. (Error Code: 500)"
❌ "네트워크 오류. 재시도하십시오."
```

### 로딩 상태
```
✅ "정보를 준비하고 있어요..."
✅ "조금만 기다려주세요."
❌ "로딩 중..."
❌ "Loading..."
```

### CTA 버튼
```
✅ "천천히 살펴보기"
✅ "다음 단계 보기"
✅ "지금은 괜찮아요" (이탈 CTA)
❌ "시작하기"
❌ "자세히 보기"
❌ "Submit"
```

## 글자 수 가이드라인

```
제목:          최대 15자 (한글 기준)
카드 설명:     최대 30자
본문 단락:     최대 3문장, 문장당 25자 이내
CTA 버튼:      최대 8자
안내 메시지:   최대 20자
```

## BeInside 전용 규칙

- 한국어 콘텐츠: "~해 보세요" (부드러운 권유체)
- 청소년 콘텐츠: 반말/해요체
- 판단적 표현 절대 금지
- 모든 전화번호에 한 줄 설명 필수

## 카피 판단 기준

| 상황 | 기준 |
|------|------|
| 카피 고민 | "새벽 3시에 혼자 읽는 사람에게 이 말이 위로가 되는가?" |
| 톤 고민 | "소리 내어 읽었을 때 자연스러운가?" |
| 길이 고민 | "한 번 읽어서 이해되는가?" — 안 되면 줄여라 |
