# BeInside 콘텐츠 작성 시스템

## 서비스 4단계 프레임워크

모든 콘텐츠는 이 흐름을 따른다:
① 상황 인식 (공감) → ② 상황 판단 (자가 체크) → ③ 행동 가이드 (실행) → ④ 도움 연결 (기관)

## 톤 시스템 — 3가지 모드

### Mode A: 기본 톤 (부모·일반 성인)
- "~해 보세요", "~할 수 있어요"
- 금지: "~해야 합니다", "~하십시오", 판단적 표현
- 통계: 수치 + "이게 무슨 의미냐면..." 한 줄 해석

### Mode B: 청소년 톤 (카드5 "나 혼자 버텨왔어" 전용)
- 반말/해요체: "~거든", "~야", "~인 거야"
- 문장 짧게. 한 문단 최대 2줄.
- "부모님" → "어른". 이모지 적극 사용.

### Mode C: 위기 톤 (긴급/자살예방)
- 극도로 짧은 문장. 공감만. 분석·설명 없음.
- "지금 많이 힘드시죠." "여기까지 온 것만으로 용기 있는 일이에요."
- 연결 수단만 제시.

## Purpose
BeInside 콘텐츠를 작성·수정할 때 사용하는 스킬. 톤, 데이터 구조, 출처, 긴급전화 정보를 일관되게 유지합니다.

## When to Use
- BeInside 콘텐츠(성장 가이드, 돌봄 가이드, 자기 돌봄 가이드) 작성·수정 시
- 새로운 데이터 객체 추가 시
- 통계·출처 업데이트 시
- 긴급전화·도움 연결 정보 추가 시

## Key References
- `references/tone-guide.md` — 3가지 톤 모드(A: 부모/성인, B: 청소년, C: 위기)와 예시
- `references/data-schema.md` — 모든 데이터 객체 스키마 (getData, MENTAL, SP_DATA 등)
- `references/source-database.md` — 통계 출처 데이터베이스
- `references/helpline-database.md` — 긴급전화·도움 연결 번호 데이터베이스
- `examples/good-content.md` — 올바른 콘텐츠 작성 예시
- `examples/bad-content.md` — 잘못된 콘텐츠 작성 예시 (안티패턴)
- `templates/content-template.json` — 빈 콘텐츠 템플릿

## Rules
1. **톤**: 반드시 `tone-guide.md`의 모드에 맞춰 작성
2. **출처**: 모든 통계 수치에 출처 명시 (source-database.md 참조)
3. **전화번호**: 반드시 `tel:` 링크 + 한 줄 설명 포함
4. **구조**: 4단계 프레임워크 준수 (상황 인식 → 상황 판단 → 행동 가이드 → 도움 연결)
5. **데이터**: data-schema.md의 필드 구조를 정확히 따를 것
6. **판단 금지**: "~해야 합니다", "~하지 않으면 안 됩니다" 등 판단적 표현 절대 금지
7. **모바일 우선**: 터치 타겟 44px 이상, CSS 변수 사용

## Workflow
1. 어떤 데이터 객체에 추가할지 결정 (data-schema.md 참조)
2. 톤 모드 결정 (대상 독자에 따라 A/B/C)
3. 4단계 프레임워크에 맞춰 콘텐츠 구조 설계
4. 통계 출처 확인 (source-database.md)
5. 긴급전화 정보 확인 (helpline-database.md)
6. good-content.md / bad-content.md와 대조하여 품질 검증

## 정보 구조 — 2단계 원칙
1단계: 핵심 3줄 + "이것만은 꼭" 경고 1개 (항상 펼침)
2단계: 상세는 아코디언 (접힌 상태)

## 실행 중심 원칙
- "이렇게 생각하세요" ❌ → "이렇게 해보세요" ⭕
- 모든 행동 가이드: 3~5단계 체크리스트

## 긴급 연락처 규칙
- 각 번호에 한 줄 설명 필수: 무료/24시간/전화하면 어떻게 되는지
- 비밀보장 단정 금지: "자세한 내용은 전화 시 확인"
- 반드시 references/helpline-database.md 참조

## 출처 규칙
- 모든 통계에 출처 명시
- references/source-database.md에서 사용 가능 출처 확인
- 새 출처 사용 시 source-database.md에 추가 + 출처 드로어 반영

## 대상 뱃지 (성장 가이드 카드)
👨‍👩‍👧 부모·보호자 | 🧒 청소년 본인 | 🙋 본인(성인) | 👀 모두

## 콘텐츠 완료 후 자동 검수
- [ ] 금지 표현 없는가? ("~해야 합니다", 판단적 표현)
- [ ] 2단계 구조인가? (핵심 요약 + 아코디언)
- [ ] 통계에 출처가 있는가?
- [ ] 긴급 연락처에 한 줄 설명이 있는가?
- [ ] 대상 뱃지가 있는가? (성장 가이드)
- [ ] 면책 조항이 있는가? (상황 판단 툴)

## Gotchas
1. "~해야 합니다" 표현 사용 — 금지. "~해 보세요"로 대체.
2. 통계 수치만 나열 — "이게 무슨 의미냐면..." 해석 추가.
3. 긴급 번호에 tel: 링크 누락 — beinside-designing 스킬과 협력.
4. 청소년 콘텐츠에 존댓말 혼입 — Mode B 톤 엄수.
5. 비밀보장 단정 — "비밀이 보장됩니다" 대신 "전화 시 확인".
