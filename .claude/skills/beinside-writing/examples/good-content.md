# 올바른 콘텐츠 예시: 번아웃 가이드 "오늘 당장 할 수 있는 것"

이 예시는 BURNOUT_DATA의 실제 구조를 기반으로, BeInside 콘텐츠 작성의 모범 사례를 보여줍니다.

---

## 1. 톤 (Mode A: 부모/성인)

```javascript
intro: {
  title: '번아웃은 게으름이 아니에요',      // 공감 먼저. "게으름이 아니에요"로 수치심 해소
  sub: '에너지가 바닥난 상태예요. 충전이 필요할 뿐이에요.',  // 원인 정상화
  stat: {
    pct: '46.3%',
    label: '심각한 스트레스를 경험한 국민 비율 (국립정신건강센터, 2024년 정신건강실태조사)'
    // 출처를 stat.label에 직접 포함
  }
}
```

### 톤 체크포인트
- "~해 보세요" 체계 사용
- "~해야 합니다" 절대 없음
- 판단적 표현 없음 ("게으른", "나약한" 등)
- 공감이 정보보다 먼저

## 2. 2단계 구조 (요약 + 아코디언 상세)

### 1단계: 오늘 당장 (항상 펼쳐져 보임)
```javascript
actions: {
  immediate: [
    {
      icon: '⏸️',
      text: '오늘 하루 업무량을 반으로 줄이세요. 안 되면 한 가지만이라도 내일로 미루세요.'
      // 구체적 행동 + 현실적 대안 ("안 되면")
    },
    {
      icon: '🚶',
      text: '점심시간에 10분만 밖에 나가 걸으세요. 햇빛 + 걷기가 세로토닌을 가장 빠르게 올려줘요.'
      // 시간 구체적(10분) + 과학적 근거(세로토닌)
    },
    {
      icon: '📱',
      text: '퇴근 후 SNS를 1시간만 줄여보세요. 비교가 번아웃의 연료예요.'
      // 구체적 수치(1시간) + 비유("연료")
    }
  ],
```

### 2단계: 이번 주 + 장기 (아코디언 안에)
```javascript
  week: [
    {
      icon: '🛌',
      text: '수면 시간을 30분만 늘려보세요. 수면이 회복의 기반이에요.'
      // 작은 단위(30분) + 이유 설명
    },
    {
      icon: '🗣️',
      text: '신뢰하는 사람 1명에게 "나 좀 지쳤어"라고 말해보세요. 말하는 것만으로도 달라져요.'
      // 구체적 대사 제공 ("나 좀 지쳤어") + 행동의 효과
    }
  ]
}
```

## 5. 행동 체크리스트 패턴

### 올바른 행동 항목 작성법
```javascript
{ icon: '⏸️', text: '오늘 하루 업무량을 반으로 줄이세요. 안 되면 한 가지만이라도 내일로 미루세요.' }
```

체크포인트:
1. **이모지**: 행동의 성격을 직관적으로 표현
2. **구체적 행동**: "업무량을 반으로 줄이세요" (추상적이지 않음)
3. **현실적 대안**: "안 되면 한 가지만이라도" (완벽하지 않아도 OK)
4. **톤**: "~세요" (권유, 명령 아님)

## 6. 도움 연결 패턴

### 올바른 help 항목
```javascript
help: [
  {
    number: '1577-0199',
    name: '정신건강위기상담전화',
    desc: '무료, 24시간. 번아웃이 심해졌을 때 언제든. 자세한 내용은 전화 시 확인해 주세요.'
  },
  {
    number: '1393',
    name: '자살예방상담전화',
    desc: '무료, 24시간. 극단적 생각이 들 때. 자세한 내용은 전화 시 확인해 주세요.'
  }
]
```

체크포인트:
1. **number**: 순수 숫자 문자열 (tel: 링크에 사용)
2. **name**: 공식 기관명
3. **desc**: 비용 + 운영시간 + 언제 전화하면 좋은지 + 마무리 문구
