# 잘못된 콘텐츠 예시: 같은 번아웃 가이드를 잘못 쓴 경우

아래는 동일한 번아웃 가이드 콘텐츠를 BeInside 규칙을 위반하여 작성한 예시입니다.
각 항목에 위반 사항을 주석으로 표시했습니다.

---

## 위반 1: 판단적 톤 ("~해야 합니다")

```javascript
// BAD
intro: {
  title: '번아웃을 방치하면 안 됩니다',          // X: 위협적 표현
  sub: '번아웃은 심각한 문제입니다. 즉시 대처해야 합니다.',  // X: "해야 합니다" 의무 부여
  stat: {
    pct: '46.3%',
    label: '스트레스를 경험한 국민 비율'   // X: 출처 누락 (기관명, 연도, 조사명 없음)
  }
}

// GOOD (비교)
intro: {
  title: '번아웃은 게으름이 아니에요',
  sub: '에너지가 바닥난 상태예요. 충전이 필요할 뿐이에요.',
  stat: {
    pct: '46.3%',
    label: '심각한 스트레스를 경험한 국민 비율 (국립정신건강센터, 2024년 정신건강실태조사)'
  }
}
```

## 위반 2: 추상적이고 강압적인 행동 가이드

```javascript
// BAD
actions: {
  immediate: [
    {
      icon: '⏸️',
      text: '업무를 줄이세요.'
      // X: 구체적이지 않음 (얼마나? 어떻게?)
      // X: 현실적 대안 없음
    },
    {
      icon: '🚶',
      text: '매일 반드시 운동을 해야 합니다. 운동하지 않으면 우울증으로 발전할 수 있습니다.'
      // X: "반드시", "해야 합니다" 명령형
      // X: "~하지 않으면 ~할 수 있습니다" 위협
      // X: 구체적 시간/방법 없음
    },
    {
      icon: '📱',
      text: 'SNS를 끊으세요.'
      // X: 극단적 지시 (줄이기가 아닌 끊기)
      // X: 이유 설명 없음
    }
  ]
}

// GOOD (비교)
actions: {
  immediate: [
    { icon: '⏸️', text: '오늘 하루 업무량을 반으로 줄이세요. 안 되면 한 가지만이라도 내일로 미루세요.' },
    { icon: '🚶', text: '점심시간에 10분만 밖에 나가 걸으세요. 햇빛 + 걷기가 세로토닌을 가장 빠르게 올려줘요.' },
    { icon: '📱', text: '퇴근 후 SNS를 1시간만 줄여보세요. 비교가 번아웃의 연료예요.' }
  ]
}
```

## 위반 3: 출처 없는 통계

```javascript
// BAD
distinction: {
  title: '번아웃 vs 우울증',
  burnout: ['직장에서만 문제', '쉬면 나아짐'],
  depression: ['모든 곳에서 문제', '쉬어도 안 나아짐'],
  note: '연구에 따르면 번아웃의 40%가 우울증으로 발전합니다.'
  // X: "연구에 따르면" — 어떤 연구? 출처 없음
  // X: "40%" — 근거 불명확한 수치
}

// GOOD (비교)
distinction: {
  note: '구분이 어렵다면 전문가 상담이 가장 정확해요. 번아웃이 방치되면 우울증으로 발전할 수 있어요.'
  // 확인되지 않은 수치 대신, "가능성" 표현으로 정직하게
}
```

## 위반 4: 도움 연결에 한 줄 설명 누락

```javascript
// BAD
help: [
  { number: '1577-0199', name: '정신건강위기상담전화', desc: '' },
  // X: desc 비어있음. 전화해서 뭘 할 수 있는지 모름

  { number: '1393', name: '자살예방상담전화' }
  // X: desc 필드 자체가 없음
]

// GOOD (비교)
help: [
  { number: '1577-0199', name: '정신건강위기상담전화', desc: '무료, 24시간. 번아웃이 심해졌을 때 언제든. 자세한 내용은 전화 시 확인해 주세요.' },
  { number: '1393', name: '자살예방상담전화', desc: '무료, 24시간. 극단적 생각이 들 때. 자세한 내용은 전화 시 확인해 주세요.' }
]
```

## 위반 5: 4단계 프레임워크 무시

```javascript
// BAD — 구조 없이 나열
container.innerHTML = `
  <h1>번아웃 가이드</h1>
  <p>번아웃이란 심각한 스트레스 상태입니다.</p>
  <ul>
    <li>운동하세요</li>
    <li>잠을 자세요</li>
    <li>전문가에게 상담받으세요</li>
  </ul>
  <p>전화: 1393</p>
`;
// X: 상황 인식 → 판단 → 행동 → 연결 구조 없음
// X: step-section, step-label 미사용
// X: stat-badge 없음 (통계 제시 안 함)
// X: 전화번호에 tel: 링크 없음
// X: 전화번호 한 줄 설명 없음

// GOOD — 4단계 프레임워크 적용
container.innerHTML = `
  <div class="content-hero">...</div>        <!-- ① 상황 인식 -->
  <div class="stat-badge">...</div>          <!-- 통계 -->
  <div class="step-section">                 <!-- ② 상황 판단 -->
    <div class="step-label">① 상황 판단</div>
    <!-- 자가 체크 도구 -->
  </div>
  <div class="step-section">                 <!-- ③ 행동 가이드 -->
    <div class="step-label">② 오늘 당장 할 수 있는 것</div>
    <div class="action-checklist">...</div>
  </div>
  <div class="step-section">                 <!-- ④ 도움 연결 -->
    <div class="step-label">④ 도움 연결</div>
    <div class="help-cards">
      <a href="tel:1393" class="help-card">...</a>
    </div>
  </div>
`;
```

## 위반 6: 청소년 대상에 성인 톤 사용

```javascript
// BAD — 청소년에게 Mode A(성인) 톤 사용
{
  icon: '💛',
  title: '이것만은 알아두세요',           // X: "~세요" 존댓말 (청소년에게)
  text: '현재 상황은 본인의 잘못이 아닙니다. 전문가에게 상담을 받으시기 바랍니다.'
  // X: "본인", "~바랍니다" — 공문서 톤
  // X: 공감 없이 바로 지시
}

// GOOD — Mode B(청소년) 톤
{
  icon: '💛',
  title: '이것만은 꼭 알아줘',
  text: '지금 네 주변 상황이 힘든 건, 네가 뭔가를 잘못해서가 아니야. 어른들의 사정이 만든 일이고, 그건 절대 네 탓이 아니야.'
}
```

## 위반 요약 체크리스트

| # | 위반 유형 | 확인 방법 |
|---|----------|----------|
| 1 | "~해야 합니다" 판단적 톤 | 전체 텍스트에서 "해야", "합니다", "반드시" 검색 |
| 2 | 추상적 행동 가이드 | 구체적 숫자(시간, 횟수)가 있는지 확인 |
| 3 | 출처 없는 통계 | stat.label에 기관명+연도+조사명 포함 여부 |
| 4 | 도움 연결 설명 누락 | help[].desc 값 확인 |
| 5 | 4단계 프레임워크 미적용 | step-section, step-label 사용 여부 |
| 6 | 대상 톤 불일치 | 청소년 콘텐츠에 반말 사용 여부 |
| 7 | tel: 링크 누락 | 전화번호에 href="tel:..." 적용 여부 |
