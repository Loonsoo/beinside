# BeInside 긴급전화·도움 연결 데이터베이스

모든 전화번호는 반드시 `tel:` 링크 + 한 줄 설명을 포함해야 합니다.

---

## 긴급 신고

### 112 — 경찰 신고
- **용도**: 아동학대·가정폭력·성폭력 신고, 범죄 신고
- **전화 시**: 신고 접수 후 경찰관이 현장 출동. 아동학대 신고 시 아동보호전문기관 연계
- **운영**: 24시간, 365일
- **비용**: 무료
- **코드에서**: `<a href="tel:112">112</a>`

### 119 — 소방/구급
- **용도**: 의료 응급, 화재, 구조
- **전화 시**: 구급대원 현장 출동. 응급 환자 이송
- **운영**: 24시간, 365일
- **비용**: 무료
- **코드에서**: `<a href="tel:119">119</a>`

## 정신건강 위기 상담

### 1393 — 자살예방상담전화
- **용도**: 자살 충동, 극단적 생각, 자해, 정신건강 위기
- **전화 시**: 전문 상담원이 즉시 응대. 경청·공감 후 필요 시 위기 개입팀 연결 또는 응급 출동 요청
- **운영**: 24시간, 365일
- **비용**: 무료
- **코드에서**: `{ number: '1393', name: '자살예방상담전화', desc: '무료, 24시간. ...' }`
- **주의**: desc에 "자세한 내용은 전화 시 확인해 주세요." 포함 권장

### 1577-0199 — 정신건강위기상담전화
- **용도**: 정신건강 전반 위기 상담 (우울, 불안, 번아웃, 고립감 등)
- **전화 시**: 정신건강 전문 상담원이 응대. 정신건강복지센터·전문 치료 기관 연계
- **운영**: 24시간, 365일
- **비용**: 무료
- **코드에서**: `{ number: '1577-0199', name: '정신건강위기상담전화', desc: '무료, 24시간.' }`

## 온라인 서비스

### 복지로 (www.bokjiro.go.kr)
- **용도**: 복지 서비스 통합 검색·신청
- **주요 서비스**: 청년 마음건강 바우처, 한부모 지원, 아이돌봄서비스, 긴급복지지원
- **사용 위치**: MENTAL.young.tips, BIRTH_DATA.todo 등

### 드림스타트
- **용도**: 취약계층 아동 통합 서비스 (건강·복지·보육·교육)
- **대상**: 0~12세 취약계층 아동 및 가족
- **신청**: 주민센터 또는 드림스타트 센터

### EAP (근로자 지원 프로그램)
- **용도**: 직장인 심리상담, 법률상담, 재무상담
- **대상**: 대기업 대부분 제공. 중소기업은 근로복지공단 EAP 이용 가능
- **비용**: 무료 (회사 부담)
- **사용 위치**: MENTAL.adult.tips, BURNOUT_DATA.actions.longterm

## 코드 작성 규칙

### help 배열 형식
```javascript
help: [
  {
    number: '1393',
    name: '자살예방상담전화',
    desc: '무료, 24시간. 극단적 생각이 들 때. 자세한 내용은 전화 시 확인해 주세요.'
  }
]
```

### HTML 링크 형식
```html
<a href="tel:1393">📞 1393</a> (자살예방상담, 무료·24시간)
```

### desc 작성 규칙
1. 운영시간 + 비용을 먼저: "무료, 24시간."
2. 언제 전화하면 좋은지 한 줄: "극단적 생각이 들 때."
3. 마무리: "자세한 내용은 전화 시 확인해 주세요."
