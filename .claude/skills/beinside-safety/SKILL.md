# BeInside 안전 콘텐츠 시스템

## 최우선 원칙
사용자의 안전 > 정보의 정확성 > 콘텐츠의 완성도 > 디자인의 아름다움

이 순서는 절대적이다.

## 빠른 탈출 버튼 사양
- 대상: 가정폭력 관련 모든 페이지
- 동작: 한 번 터치 → 네이버 메인 이동 + history.replaceState로 기록 대체
- 위치: 우상단 고정, z-index 최상위
- 크기: 최소 44px × 44px
- 라벨: "✕" 또는 "나가기" (가해자가 봐도 모호하게)
- references/crisis-ux-patterns.md에서 구현 코드 확인

## "죽고 싶다" 경로
- 감정 가이드에서 해당 옵션 선택 시 전용 화면으로 전환
- 화면: 흰색 배경, 큰 글씨, 여백 넉넉
- 콘텐츠: 공감 2줄 + 연결 수단만. 분석·설명·통계·다른 콘텐츠 없음
- 연결: 1393 전화 버튼 + 카카오톡 상담 링크
- references/suicide-prevention-guide.md 반드시 참조

## 가정폭력 콘텐츠 규칙
- "왜 떠나지 않나요?" 류의 피해자 탓 표현 절대 금지
- 가해자가 볼 수 있음을 전제로 UI 설계
- 실행 가능한 체크리스트 형태 우선
- references/domestic-violence-guide.md 참조

## 청소년 페이지 기록 차단
- localStorage 사용 금지
- "기록에 남지 않아요" 명시
- 위험한 어른 구별법 섹션 포함 (그루밍 예방)
- references/child-safety-guide.md 참조

## 면책 조항
모든 상황 판단 툴 결과 하단에:
"이 결과는 참고용이며, 의학적·심리학적 진단을 대체하지 않습니다."

## Gotchas
1. 비밀보장 단정 — "비밀이 보장됩니다" 금지. 상황마다 다르다.
2. 자살 방법 기술 — 절대 구체적으로 기술하지 않는다.
3. "극단적 선택" 완곡어 사용 — 오히려 직접적 표현("자살")이 도움이 된다.
4. 위기 페이지에 광고·통계·장식 — 오직 연결 수단만.
5. 청소년 페이지에서 localStorage 사용 — 기록 차단 원칙 위반.
