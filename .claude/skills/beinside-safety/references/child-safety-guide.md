# 아동·청소년 안전 콘텐츠 가이드

이 문서는 아동학대 예방, 그루밍 예방, 청소년 위기 지원 콘텐츠의 작성 및 UI 규칙을 정의한다.

---

## 1. 기록 차단 원칙

청소년이 도움을 구하는 행위가 가해자(보호자, 교사 등)에게 노출되면 위험이 커진다.
따라서 청소년 대상 페이지는 브라우징 흔적을 최소화한다.

### 기술적 규칙
- `localStorage` 사용 **절대 금지**
- `sessionStorage` 사용 금지
- 쿠키 설정 금지
- 방문 기록 최소화: 가능한 경우 `history.replaceState` 활용
- URL에 민감한 키워드 금지 (예: `/child-abuse` 대신 `/help/youth`)
- `document.title`에 민감한 키워드 금지

### 사용자 안내 문구
페이지 상단 또는 진입 시 아래 문구를 표시한다:

> "기록에 남지 않아요."

이 문구는 짧고 명확하게, 눈에 잘 띄는 위치에 배치한다.
단, 기술적으로 완전한 기록 삭제를 보장할 수는 없으므로
"이 사이트는 방문 기록을 저장하지 않아요"라고 표현한다 (브라우저 기록까지 삭제하는 것은 아님).

## 2. 그루밍 예방: "위험한 어른 구별법"

아동·청소년이 그루밍(grooming)을 인지하고 스스로를 보호할 수 있도록 돕는 콘텐츠.

### 콘텐츠 구성

#### "이런 어른은 조심해요" (체크리스트 형태)

- "다른 사람에게 비밀로 하자"고 하는 어른
- 선물이나 돈을 주면서 특별한 관계를 만들려는 어른
- 둘만 있으려고 자꾸 상황을 만드는 어른
- 몸을 만지거나, 만지게 하거나, 보여달라고 하는 어른
- "네가 좋아서 그래" "너만 특별해"라고 하면서 불편한 행동을 하는 어른
- 화를 내거나 벌을 주겠다고 위협하는 어른
- SNS나 메신저로 은밀하게 연락하려는 어른

#### "이럴 때는 이렇게 해요"

- "싫어요"라고 말해도 돼요. 어른이라도 거절할 수 있어요.
- 그 자리를 벗어나도 돼요.
- 믿을 수 있는 다른 어른에게 이야기해요.
- 혼자 해결하지 않아도 돼요.
- 전화로 도움을 요청할 수 있어요: 112, 1388

#### "이건 네 잘못이 아니에요"

반드시 포함할 메시지:
- "어떤 상황이든 네 잘못이 아니에요."
- "이야기해 줘서 고마워요."
- "도움을 요청하는 건 용기 있는 거예요."

### 콘텐츠 작성 시 주의사항
- 구체적인 학대 장면이나 방법을 묘사하지 않는다.
- 공포를 유발하는 표현을 사용하지 않는다.
- 아동이 이해할 수 있는 쉬운 언어를 사용한다.
- 모든 어른이 위험하다는 인상을 주지 않는다.

---

## 3. 언어 톤 (Mode B: 청소년 톤)

청소년 대상 콘텐츠는 해요체/반말을 사용한다.

### 톤 규칙
- 해요체 또는 부드러운 반말
- 짧은 문장
- 쉬운 단어
- 판단적 표현 금지
- "~해야 한다" 대신 "~해도 돼요", "~할 수 있어요"

### 예시

| 일반 톤 | 청소년 톤 (Mode B) |
|---------|-------------------|
| 학대 상황에서는 신고해야 합니다 | 힘든 일이 있으면 전화해도 돼요 |
| 전문 상담을 권장합니다 | 이야기 나눌 수 있는 곳이 있어요 |
| 피해 사실을 기록하십시오 | 기억나는 걸 메모해 둬도 좋아요 |

## 4. 청소년 긴급 연락처

| 기관 | 전화번호 | 설명 |
|------|----------|------|
| 청소년 전화 | [1388](tel:1388) | 24시간, 청소년 전용 상담 전화 |
| 경찰 | [112](tel:112) | 긴급 신고, 학대·폭력 신고 |
| 아동보호전문기관 | [1577-0199](tel:1577-0199) | 아동학대 상담 및 신고 |
| 자살예방상담전화 | [109](tel:109) | 24시간, 무료 |

### 연락처 표시 규칙
- 모든 번호에 `tel:` 링크 필수
- 한 줄 설명 필수 ("24시간", "무료", "청소년 전용" 등)
- 1388을 가장 크고 눈에 띄게 (청소년이 가장 먼저 볼 수 있도록)
- 터치 타겟 최소 44px x 44px

## 5. 아동학대 인지 콘텐츠

아동·청소년이 자신의 상황을 인지할 수 있도록 돕되, 구체적인 학대 묘사는 하지 않는다.

### "혹시 이런 일이 있나요?" (인지 체크리스트)

- 어른이 자주 때리거나 아프게 하나요?
- 밥을 안 주거나, 집에 혼자 오래 있나요?
- 무섭거나 불안한 일이 자꾸 생기나요?
- 어른이 하는 행동 때문에 몸이나 마음이 아픈가요?
- 누구에게도 말하지 말라고 하나요?

### 주의사항
- "학대"라는 단어를 직접 사용하기보다 상황을 묘사한다 (아동이 자신의 상황을 "학대"로 인지하지 못할 수 있음).
- 공포를 유발하는 표현을 쓰지 않는다.
- "이런 일이 있으면 네 잘못이 아니에요"를 반드시 포함한다.
- 도움을 요청하는 방법을 구체적으로 안내한다.

## 6. UI 설계 규칙

### 빠른 탈출 버튼
- 청소년 안전 페이지에도 빠른 탈출 버튼을 포함한다.
- 구현은 `crisis-ux-patterns.md` 참조.

### 색상 및 디자인
- 위기 화면은 흰색 배경, 최소 장식.
- 일반 안전 정보 페이지는 프로젝트 디자인 시스템을 따르되, 밝고 안정감 있는 톤.
- 공포를 유발하는 어두운 색상이나 이미지 금지.

### 인터랙션
- 화면당 선택지 최대 3개.
- 버튼 텍스트는 동사로 시작: "전화하기", "이야기하기", "나가기".
- 폰트 크기 최소 16px.
