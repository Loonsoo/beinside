# 가정폭력 콘텐츠 가이드

이 문서는 가정폭력 관련 콘텐츠를 작성하고 UI를 설계할 때의 규칙을 정의한다.
**핵심 전제: 가해자가 이 화면을 볼 수 있다.**

---

## 1. 콘텐츠 규칙

### 절대 금지 표현

| 금지 표현 | 이유 | 대안 |
|-----------|------|------|
| "왜 떠나지 않나요?" | 피해자 탓 | 사용하지 않음 (질문 자체가 불필요) |
| "떠나세요" / "신고하세요" | 단순 지시는 위험을 높일 수 있음 | "안전하게 도움받을 수 있는 방법이 있어요" |
| "당신이 참으면 안 됩니다" | 피해자에게 책임 전가 | "이 상황은 당신의 잘못이 아니에요" |
| "폭력은 대물림됩니다" | 공포 유발, 피해자 죄책감 | 사용하지 않음 |
| "비밀이 보장됩니다" | 상황에 따라 다름 (신고의무 등) | "상담 내용의 비밀보장 범위는 상담 시 안내받을 수 있어요" |
| "가해자도 힘들었을 거예요" | 폭력 합리화 | 사용하지 않음 |
| "서로 노력하면" | 관계 수정 압력 | 사용하지 않음 |
| "아이를 위해서" | 피해자 희생 강요 | 사용하지 않음 |

### 권장 표현

- "지금 이 상황은 당신의 잘못이 아니에요."
- "도움을 요청하는 것은 용기 있는 일이에요."
- "당신의 안전이 가장 중요해요."
- "준비가 되었을 때, 연결할 수 있는 곳이 있어요."
- "지금 바로가 아니어도 괜찮아요. 알아 두기만 해도 돼요."

### 콘텐츠 형태
- 분석이나 설명보다 **실행 가능한 체크리스트** 형태를 우선한다.
- 행동 단계를 구체적으로 안내한다.
- "~해 보세요" (부드러운 권유체)를 사용한다.

## 2. UI 규칙

### 빠른 탈출 버튼
- 가정폭력 관련 모든 페이지에 필수.
- 구현 방법은 `crisis-ux-patterns.md` 참조.
- 스크롤과 무관하게 항상 우상단에 고정.

### 페이지 타이틀
- 중립적으로 설정: `document.title = 'BeInside'`
- "가정폭력", "학대", "상담" 등의 키워드를 타이틀에 넣지 않는다.
- 브라우저 탭, 최근 방문 목록에 민감한 내용이 노출되면 안 된다.

### 데이터 저장 금지
- `localStorage` 사용 금지
- `sessionStorage` 사용 금지
- 쿠키 설정 금지
- 방문 기록이 최소화되도록 `history.replaceState` 활용

### 화면 설계
- 한 화면에 선택지 최대 3개
- 전화번호는 반드시 `tel:` 링크
- 터치 타겟 최소 44px x 44px

## 3. 안전 계획 체크리스트 템플릿

가정폭력 피해자를 위한 안전 계획 체크리스트.
이 내용을 페이지에 적용할 때 체크리스트 형태로 제공한다.

### 미리 준비할 수 있는 것들

```
□ 신분증 사본을 안전한 곳에 보관하기
□ 비상금을 따로 마련해 두기
□ 믿을 수 있는 사람 1명에게 상황 알리기
□ 긴급할 때 갈 수 있는 장소 정해 두기
□ 중요 연락처를 외워 두기 (1366, 112)
□ 병원 진료 기록 보관하기 (진단서, 사진)
```

### 위급할 때

```
□ 112에 전화하기 (경찰)
□ 1366에 전화하기 (여성긴급전화, 24시간)
□ 안전한 장소로 이동하기
□ 주변 사람에게 도움 요청하기
```

### 주의사항
- 이 체크리스트는 화면에 표시하되, 저장/다운로드 기능은 제공하지 않는다.
- "이 목록을 캡처하거나 메모해 두세요"라는 안내는 하지 않는다 (가해자가 볼 수 있음).
- 사용자가 스스로 기억하거나 머릿속으로 계획할 수 있도록 돕는다.

## 4. 긴급 연락처

모든 전화번호에 `tel:` 링크와 한 줄 설명을 포함한다.

| 연락처 | 전화번호 | 설명 |
|--------|----------|------|
| 여성긴급전화 | [1366](tel:1366) | 24시간, 가정폭력·성폭력 상담 및 긴급 보호 |
| 경찰 | [112](tel:112) | 긴급 신고, 현장 출동 |
| 아동보호전문기관 | [112](tel:112) | 아동학대 신고 (경찰 통합) |
| 법률구조공단 | [132](tel:132) | 무료 법률 상담 |
| 가정폭력 피해자 보호시설 | [1366](tel:1366) | 1366 통해 가까운 보호시설 연결 |

### 연락처 표시 규칙
- 전화번호는 크고 눈에 띄게 표시
- 각 번호 아래에 한 줄 설명 필수
- 운영시간 명시 (24시간인 경우 "24시간" 표기)
- "무료"인 경우 반드시 표기

## 5. 법적 고지 사항

### 신고 의무
- 아동학대가 동반된 경우, 일부 직군은 신고 의무가 있음을 안내할 수 있다.
- 단, "신고됩니다"라는 경고 톤은 피해자를 위축시킬 수 있으므로 주의한다.

### 면책 조항
페이지 하단에 반드시 포함:
> "이 정보는 참고용이며, 법률적 조언을 대체하지 않습니다. 구체적인 법률 문제는 법률구조공단(132)에 문의해 주세요."
