# 자살예방 콘텐츠 가이드

이 문서는 WHO 미디어 가이드라인을 웹 콘텐츠에 맞게 적용한 자살예방 콘텐츠 규칙이다.
생명과 직결되는 내용이므로 모든 규칙을 예외 없이 준수한다.

---

## 1. 언어 규칙

### 용어 사용

| 사용해야 하는 표현 | 사용하지 않는 표현 | 이유 |
|---|---|---|
| 자살 | 극단적 선택 | 완곡어는 문제의 심각성을 흐린다. WHO 권고 |
| 자살 | 스스로 목숨을 끊다 | 불필요하게 구체적 |
| 자살로 사망했다 | 자살에 성공했다 | "성공"은 긍정적 의미를 내포 |
| 자살 시도 | 자살에 실패했다 | "실패"는 부정적 의미를 내포 |
| 사망률 | 자살률 (수치와 함께) | 위기 화면에서 통계 사용 자체를 금지 |

### 절대 금지 사항
- **자살 방법을 구체적으로 기술하지 않는다.** 어떤 맥락에서도 예외 없음.
- **자살 장소를 구체적으로 언급하지 않는다.**
- **유서 내용을 인용하지 않는다.**
- **자살을 낭만화, 미화, 선정적으로 다루지 않는다.**
- **자살 사건의 사진이나 영상을 사용하지 않는다.**
- **통계 수치를 위기 화면에 표시하지 않는다.** (모방 효과 위험)

### 권장 표현 (Mode C: 위기 톤)
- "지금 많이 힘드시죠."
- "여기까지 찾아와 주셔서 감사해요."
- "혼자 감당하지 않아도 돼요."
- "지금 바로 이야기 나눌 수 있는 곳이 있어요."

Mode C 톤의 특징:
- 극도로 짧은 문장
- 공감 표현 1~2줄만
- 설명, 분석, 조언 없음
- 오직 공감 + 연결 수단

## 2. "죽고 싶다" 화면 사양

감정 가이드에서 "죽고 싶다" 또는 이에 준하는 옵션을 선택했을 때 표시되는 전용 화면.

### 표시할 것 (이 순서대로, 이것만)

1. **공감 문장 2줄**
   ```
   지금 많이 힘드시죠.
   혼자 감당하지 않아도 돼요.
   ```

2. **자살예방상담전화 버튼**
   ```html
   <a href="tel:1393" class="crisis-call-btn">
     <span class="crisis-call-label">자살예방상담전화</span>
     <span class="crisis-call-number">1393</span>
     <span class="crisis-call-desc">24시간, 무료</span>
   </a>
   ```

3. **카카오톡 상담 링크**
   ```html
   <a href="https://talk.kakao.com/emoticon/store" class="crisis-chat-btn">
     카카오톡으로 상담하기
   </a>
   ```
   (실제 카카오톡 상담 URL은 정신건강위기상담전화 공식 채널 확인 후 적용)

4. **면책 조항** (작은 글씨)
   ```
   이 결과는 참고용이며, 의학적·심리학적 진단을 대체하지 않습니다.
   ```

### 절대 표시하지 않을 것
- 내비게이션 메뉴
- 다른 콘텐츠로의 링크 ("이런 글도 읽어보세요" 등)
- 통계 수치 ("한국의 자살률은..." 등)
- 자살 원인 분석
- 장식 요소 (일러스트, 아이콘, 그라데이션)
- 광고
- 공유 버튼
- 자살 방법에 대한 어떤 언급
- 유명인 자살 사례
- "힘내세요", "긍정적으로 생각하세요" 등의 조언

### 화면 디자인
- 배경: 흰색 (`#ffffff`)
- 글씨: 크고 읽기 쉽게 (22px 이상)
- 여백: 넉넉하게 (`padding: 40px 24px`)
- 요소 간 간격: 충분히 (`gap: 16px` 이상)
- 구현 세부사항은 `crisis-ux-patterns.md`의 `.crisis-screen` 참조

## 3. 연결 수단

### 주요 연락처

| 기관 | 전화번호 | 설명 |
|------|----------|------|
| 자살예방상담전화 | [1393](tel:1393) | 24시간, 무료, 전문 상담 |
| 정신건강위기상담전화 | [1577-0199](tel:1577-0199) | 24시간, 무료, 정신건강 전문 상담 |
| 생명의전화 | [1588-9191](tel:1588-9191) | 24시간, 자살예방 상담 |
| 청소년 전화 | [1388](tel:1388) | 24시간, 청소년 전용 |

### 연락처 표시 규칙
- 위기 화면에서는 1393 하나만 크게 표시한다 (선택지 최소화).
- 추가 연락처는 1393 아래에 작게 표시하거나, 별도 도움 페이지에 모은다.
- 모든 번호에 `tel:` 링크 필수.
- "24시간", "무료" 등 핵심 정보 한 줄 설명 필수.

## 4. WHO 미디어 가이드라인 핵심 요약

(웹 콘텐츠에 적용한 요약)

1. **도움을 구할 수 있다는 메시지를 전달한다.**
2. **자살 방법을 보도하지 않는다.** → 웹에서도 방법을 기술하지 않는다.
3. **자살 장소를 구체적으로 언급하지 않는다.**
4. **선정적인 제목을 사용하지 않는다.** → 페이지 타이틀, 섹션 제목 모두 해당.
5. **사진이나 영상을 사용하지 않는다.** → 관련 이미지 사용 금지.
6. **유명인 자살을 특별히 다루지 않는다.** → 사례로 인용하지 않는다.
7. **자살 유가족을 배려한다.**
8. **도움을 받을 수 있는 곳을 안내한다.** → 연결 수단 필수 포함.

## 5. 콘텐츠 작성 시 자기 점검

자살예방 관련 콘텐츠를 작성한 후 아래를 확인한다:

- [ ] 자살 방법이 직접적이든 간접적이든 기술되어 있지 않은가?
- [ ] 자살 장소가 언급되어 있지 않은가?
- [ ] "극단적 선택" 대신 "자살"을 사용했는가?
- [ ] 통계 수치가 위기 화면에 표시되지 않는가?
- [ ] 공감 표현이 1~2줄로 짧은가?
- [ ] 연결 수단(전화, 채팅)이 포함되어 있는가?
- [ ] 전화번호에 `tel:` 링크가 있는가?
- [ ] 조언("힘내세요", "긍정적으로")이 없는가?
- [ ] 다른 콘텐츠로의 링크가 위기 화면에 없는가?
- [ ] 면책 조항이 포함되어 있는가?
- [ ] 페이지 타이틀이 중립적인가?
