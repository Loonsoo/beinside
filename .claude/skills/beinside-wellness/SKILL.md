# BeInside 일상 정신건강 콘텐츠 감수 시스템

## beinside-safety와의 역할 분담

- safety = **위기 상황** (자살, 가정폭력, 아동학대) 전용
- wellness = **일상 정신건강** (감정, 번아웃, 수면, 상실, 관계, 스트레스) 감수

## 왜 별도 스킬이 필요한가

위기 콘텐츠는 beinside-safety가 잘 잡고 있지만,
일상 정신건강 콘텐츠에서 발생하는 미묘한 문제들 —
"뇌과학 설명의 과도한 단정", "자가점검 결과의 과잉 해석 유도",
"대처 기법의 무조건적 권유" — 은 전용 검증 없이 통과될 수 있다.

## 검증 영역

### 1. 심리학 용어 정확성

```
□ 심리학 개념 인용 시 원래 이론과 부합하는가?
□ 과도한 단순화로 오해를 유발하지 않는가?
□ 출처 논문/교과서를 명시할 수 있는가?
□ CBT, 행동 활성화, 애착이론 등 학술 개념이 정확한가?
```

### 2. 뇌과학/신경과학 주장

#### 주의가 필요한 표현들
| 위험 표현 | 안전한 대체 |
|----------|-----------|
| "세로토닌 분비를 올려줘요" (단정) | "세로토닌 분비에 영향을 줄 수 있어요" |
| "편도체가 활성화되면..." (확정) | "편도체 활성화와 관련이 있다고 알려져 있어요" |
| "코르티솔이 과잉 분비돼요" (단정) | "코르티솔 수치가 높아질 수 있어요" |

#### 규칙
- 뇌과학 설명은 "~할 수 있어요" (가능성)로 서술
- "~해요", "~됩니다" (단정)은 메타분석 수준의 강한 근거가 있을 때만
- 대중 과학 수준의 단순화는 허용하되, 인과관계를 상관관계로 바꾸지 않기

### 3. 자가점검 결과 표현

```
□ 점검 결과가 진단을 암시하지 않는가?
□ threshold 기준이 과잉/과소 분류를 유도하지 않는가?
□ "당신은 ~일 수 있습니다" (진단적) → "이런 부분을 돌아볼 수 있어요" (탐색적)
□ 모든 결과에 "정식 진단 도구가 아닙니다" 면책 포함
□ high 결과에 전문가 연결 정보 필수
```

### 4. 대처 기법 안전성

#### 주의가 필요한 기법들
| 기법 | 주의사항 |
|-----|---------|
| 호흡법 (박스 호흡 등) | PTSD 환자에게 해리 촉발 가능 |
| 인지 재구성 | 급성 위기 시 비효과적, 오히려 자기비난 유발 가능 |
| 감정 일기 | 반추(rumination) 강화 가능성 |
| 마인드풀니스 | 해리 증상 환자에게 부적절할 수 있음 |
| 운동 권유 | 신체적 제한이 있는 사람 고려 |

#### 규칙
- 모든 대처 기법에 "이 방법이 맞지 않을 수도 있어요" 주의 문구
- "이 방법이 불편하다면 무리하지 않아도 돼요" 탈출구 제공
- 특정 기법이 유일한 해결책인 것처럼 제시하지 않기
- 복수의 대안 제시 (최소 2가지)

### 5. 근거 수준 관리

#### 3단계 분류
| 수준 | 근거 | 표현 |
|-----|------|------|
| A (강함) | 메타분석, RCT 다수 | "연구에서 확인되었어요" |
| B (중간) | RCT 소수, 관찰 연구 | "도움이 될 수 있다는 연구가 있어요" |
| C (약함) | 전문가 의견, 사례 보고 | "도움이 된다고 알려져 있어요" |

#### 규칙
- 치료 효과 수치("80% 이상 개선")는 반드시 출처 명시
- 수준 B 이하 근거의 기법은 단정적 표현 금지
- 통계 연도: 3년 이내 권장, 초과 시 "최신 확인 필요" 표시

### 6. 감정 착지 안내

깊은 감정적 콘텐츠(혼자 버텨온 사람, 상실, 트라우마 등)를 읽은 후
사용자의 감정을 안전하게 착지시키는 안내가 필요:

```
읽고 나서 마음이 많이 움직였다면...
지금 느끼는 감정은 자연스러운 거예요.
잠시 숨을 고르고, 주변을 한번 둘러봐 보세요.
필요하다면 가까운 사람에게 연락해 보는 것도 좋아요.
```

## 일상 → 위기 전환 관리

### emergencyIndex 일관성
- 모든 자가점검 도구에 emergencyIndex 정의 필수
- emergency 트리거 항목 (예: "나를 해치고 싶다")의 표현과 동작이 모든 페이지에서 동일해야 함
- emergency 발동 시: 즉각 위기 화면 전환 + 109/1577-0199 연결

### 전문가 연결의 구체성
"전문가와 상담해 보세요"만으로는 부족. 구체적 경로 안내:
- **어디서**: 정신건강복지센터 (전국 무료)
- **어떻게**: 복지로(www.bokjiro.go.kr) 검색 또는 보건소 방문
- **비용**: 무료 (국가 지원)
- **전화**: 1577-0199 (정신건강위기상담전화)

## 콘텐츠 감수 체크리스트

```
□ 심리학 용어가 원래 이론과 부합
□ 뇌과학 설명이 "~수 있어요"로 서술
□ 자가점검 결과가 진단을 암시하지 않음
□ 대처 기법에 "맞지 않을 수도 있어요" 주의 문구
□ 치료 효과 수치에 출처 명시
□ 통계 연도 3년 이내
□ 깊은 감정 콘텐츠 뒤 착지 안내 포함
□ emergencyIndex 로직 존재 및 일관성
□ 전문가 연결에 구체적 경로 포함
□ 복수의 대안 제시 (최소 2가지)
```
