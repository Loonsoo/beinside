# BeInside 법적 컴플라이언스 시스템

## 3대 법적 리스크 영역

### 1. 개인정보보호

#### localStorage 데이터 현황
| 키 | 내용 | 개인정보 해당 | 조치 |
|---|------|-------------|------|
| profiles | 프로필, 아바타 | 가능성 있음 | 처리방침 명시 |
| memos | 메모 내용 | 개인정보 | 처리방침 명시 |
| mood | 감정 기록 | 민감정보 가능 | 최소 수집, 90일 삭제 |
| journal | 저널 내용 | 개인정보 | 처리방침 명시 |
| theme | 다크모드 설정 | 아님 | - |
| cardOrder | 카드 순서 | 아님 | - |
| onboardDone | 온보딩 상태 | 아님 | - |

#### 필수 조치
- **개인정보처리방침 페이지 필요** (정보통신망법 제27조의2)
  - 수집 항목, 목적, 보관 기간, 파기 방법
  - localStorage는 기기 내 저장이므로 "수집"이 아닌 "저장 지원"으로 구분
  - 제3자 제공: Umami (쿠키리스, IP 미수집 명시), Vercel, Google Fonts
- **청소년 데이터 특별 보호**: 14세 미만 법정대리인 동의 이슈 검토

#### Umami 분석 프라이버시
- 쿠키리스: O
- IP 미수집: O (Umami Cloud 기본 설정)
- 위기 행동 추적 주의: 긴급전화 클릭 추적은 허용, 구체적 위기 내용 추적은 금지

### 2. 면책 조항

#### 3종 면책 템플릿

**A. 일반 정보 면책**
```
이 정보는 참고용이며, 전문적인 의료·법률·심리 상담을 대체하지 않습니다.
```

**B. 자가점검 도구 면책** (★ "자가진단" 용어 사용 금지 — 의료법 리스크)
```
이 점검은 정식 진단 도구가 아닙니다.
결과에 관계없이 어려움이 지속된다면 전문가와 상담해 보세요.
```

**C. 위기 상황 면책**
```
지금 힘든 상황이라면, 전문 상담사와 이야기해 보세요.
자살예방상담전화 109 (24시간)
```

#### 면책 배치 규칙
- 모든 자가점검 결과 하단에 B 템플릿 필수
- 정신건강 가이드 페이지 하단에 A 템플릿 필수
- 위기 관련 콘텐츠에 C 템플릿 필수
- 면책 문구: 본문과 동일한 가독성 (작은 글씨로 숨기지 않기)

### 3. 콘텐츠 법적 경계

#### 의료법 경계선 용어

| 사용 금지 | 대체 표현 |
|----------|----------|
| 자가진단 | 자가점검, 자기 돌아보기 |
| 치료법 | 도움이 되는 방법 |
| 처방 | 제안, 추천 |
| 진단 결과 | 점검 결과 |
| 회복 처방전 | 회복 가이드 |
| ~에 효과적입니다 (단정) | ~에 도움이 될 수 있어요 |

#### 자살예방법 준수 (제19조)

- 자살 방법·수단 구체적 묘사 절대 금지
- 자살을 미화·정당화하는 표현 금지
- 생존자 비난 금지
- 반드시 도움 연결 정보 포함
- WHO 자살보도 가이드라인 준수

#### 아동학대 신고 안내
- 아동복지법 제10조의2: 신고의무자 안내
- 신고 방법: 112 (경찰) 또는 아동보호전문기관
- "의심 시 신고해도 됩니다" — 확인이 아닌 의심 단계에서 신고 가능함을 안내

## 관련 법률 목록

| 법률 | 관련 영역 |
|-----|----------|
| 개인정보 보호법 | localStorage, 분석 데이터 |
| 정보통신망법 | 웹서비스 운영, 이용약관 |
| 정신건강복지법 | 정신건강 콘텐츠 기준 |
| 자살예방법 | 자살 관련 콘텐츠 규제 |
| 의료법 | 의료행위/정보 경계 |
| 아동복지법 | 아동학대 신고 안내 |
| 장애인차별금지법 | 웹 접근성 |
| 다문화가족지원법 | 다국어 정보 제공 |
| 저작권법 | 콘텐츠·폰트 라이선스 |

## 컴플라이언스 체크리스트 (배포 전)

```
□ 개인정보처리방침 링크 존재 (footer)
□ 면책 조항이 모든 자가점검 도구에 포함
□ "자가진단" 용어 미사용 ("자가점검" 사용)
□ 치료 효과 수치 인용 시 출처 명시
□ 자살 방법 묘사 없음
□ 모든 위기 콘텐츠에 도움 연결 정보 포함
□ 전화번호 정확성 확인 (최신)
□ Umami에서 민감 행동 미추적
```
