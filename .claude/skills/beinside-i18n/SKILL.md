# BeInside 다국어 지원 시스템

## 언어 우선순위
1. 베트남어 (Tiếng Việt) — 한국 내 다문화 가정 최다 비율
2. 중국어 간체 (简体中文)
3. 영어 (English)

## 번역 3단계
1단계: 긴급 연락처 + 카드 제목 (생존 정보)
2단계: 핵심 요약 문장들
3단계: 전체 콘텐츠

## 번역 규칙
- 직역 금지 — 문화적 맥락에 맞게 의역
- "한국에서는 이렇게 해요" 형식으로 문화 차이 설명
- 전화번호는 국제 형식 포함 (+82-XXX)
- 존댓말/반말 구분은 각 언어 관습에 맞게

## 문화 차이 콘텐츠 원칙
- 판단 없이 설명
- "당신 나라에서는 이럴 수 있지만, 한국에서는..." 형식 금지
- "한국 생활에서 알아두면 좋은 것" 형식 사용

## Gotchas
1. 한국어 존댓말을 그대로 직역 — 각 언어 관습에 맞게 조절
2. 긴급 번호를 현지 번호로 변경 — 한국 번호 유지 + 국제 형식 추가
3. 문화적 가정 — "결혼한 여성"을 전제하는 등의 표현 주의

## 관련 스킬
- 콘텐츠 원본 → `beinside-writing`
- UI 구현 → `beinside-designing`
