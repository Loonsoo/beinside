# 다국어 지원 언어 우선순위

## 왜 베트남어가 첫 번째인가

### 통계 근거
- 한국 내 결혼이민자 중 베트남 출신 비율이 가장 높음 (약 30% 이상)
- 다문화 가정 자녀 중 베트남계가 최다
- 베트남 출신 이민자의 한국어 능력 격차가 상대적으로 큼
- 긴급 상황 시 모국어 정보 접근이 가장 절실한 그룹

### 우선순위 순서
1. **베트남어 (Tiếng Việt)** — 최다 비율 + 정보 접근 격차 큼
2. **중국어 간체 (简体中文)** — 두 번째 비율, 조선족 포함
3. **영어 (English)** — 기타 국적 커버 + 국제 표준

## 번역 품질 가이드라인

### 공통
- 전문 용어는 한국어 원문을 괄호로 병기: "산후조리원 (Trung tâm chăm sóc sau sinh)"
- 전화번호는 반드시 국제 형식 포함: 1393 → 1393 (+82-2-1393)
- 기관명은 한국어 + 번역 병기

### 베트남어 (Tiếng Việt)
- 남부 표준어(호치민 방언) 기준
- 존칭: "bạn" (당신) 사용, "anh/chị"는 문맥에 따라
- 의료/법률 용어는 한국어 원문 병기 필수

### 중국어 간체 (简体中文)
- 대륙 표준 간체자 사용 (번체 아님)
- "您" (존칭) 사용
- 조선족 사용자 고려하여 한국 관련 용어는 한국어 병기

### 영어 (English)
- 미국식 영어 기준
- 간결하고 명확한 문장
- 문화 특수 개념은 간단한 설명 추가
