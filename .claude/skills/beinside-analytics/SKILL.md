# BeInside Analytics 시스템

## 분석 도구
- **Umami Analytics**: 프라이버시 친화적 (쿠키리스, IP 비수집)
- 현재 설정: `data-auto-track="false"` → 수동 추적 모드
- `umami.track()` 호출로 이벤트 전송

## 핵심 지표 (KPI)

### North Star Metric
**"도움이 필요한 순간에 실제로 도움이 되었는가"**

### 참여 지표
- 페이지뷰 / 고유 방문자 (일간, 주간, 월간)
- 평균 체류 시간 (특히 가이드 페이지)
- 바운스율 (메인 → 콘텐츠 진입율)
- 카드/아코디언 열람율

### 기능 사용 지표
- 무드 트래커 기록 빈도
- 저널 작성 빈도
- 메모 저장 빈도
- 다크모드 전환 비율

### 도움 연결 지표 (가장 중요)
- 전화번호 `tel:` 링크 클릭률
- 위기 경로 도달률
- 빠른 탈출 버튼 사용률
- 체크리스트 완료율

### 성능 지표
- Lighthouse 점수 추이
- FCP / LCP / CLS

## 이벤트 네이밍 컨벤션

```
형식: {카테고리}_{액션}
예시: page_view, helpline_click, mood_log, checklist_complete
```

### 필수 이벤트 목록

| 이벤트명 | 트리거 | 용도 |
|---------|--------|------|
| `page_view` | 페이지 전환 | 콘텐츠별 인기도 |
| `helpline_click` | tel: 링크 클릭 | 도움 연결 측정 |
| `sos_click` | 빠른 탈출 버튼 | 위기 사용자 파악 |
| `accordion_open` | 아코디언 펼치기 | 콘텐츠 관심도 |
| `mood_log` | 무드 기록 | 기능 활용도 |
| `journal_write` | 저널 작성 | 기능 활용도 |
| `checklist_complete` | 체크리스트 완료 | 행동 전환율 |
| `share_click` | 공유 버튼 | 확산도 |
| `theme_toggle` | 다크모드 전환 | 설정 사용률 |

## 프라이버시 규칙 (절대 준수)

### 추적 금지 목록
- 감정 일기/저널 내용
- 구체적 위기 상황 정보
- 자가진단 결과 상세
- 무드 트래커 감정 값
- 프로필 정보
- IP 주소, 기기 고유 식별자

### 추적 허용 목록
- 페이지뷰 (어떤 페이지를 방문했는지)
- 버튼 클릭 (어떤 CTA를 눌렀는지)
- 기능 사용 여부 (무드를 기록했는지 — 내용은 아님)
- 체류 시간

## Umami 코드 패턴

```javascript
// 페이지뷰 (showPage에서)
if (typeof umami !== 'undefined') {
  umami.track(props => ({ ...props, url: '/' + pageId, title: pageTitle }));
}

// 이벤트 (사용자 액션에서)
if (typeof umami !== 'undefined') {
  umami.track('helpline_click', { page: currentPage });
}
```

## 분석 보고 형식

```
## [분석 제목]

### 요약
- 핵심 발견 1~3줄

### 데이터
- 지표와 수치 (비교 기준 포함)

### 해석
- "이게 무슨 의미냐면..." (맥락 해석)

### 제안
- 구체적 개선 액션 1~3개
```

## 주의사항

- 위기 콘텐츠의 "낮은 체류시간"은 부정적이 아닐 수 있음 (빠른 도움 연결 = 성공)
- A/B 테스트 시 위기 경로는 테스트 대상에서 절대 제외
- 통계적 유의성 없는 데이터로 결론 내리지 않기
- 다크 패턴(중독 유도) 설계 제안 절대 금지
