## 가이드별 검토일 표시 구현 제안

**현재 구조 확인 결과: 데이터 필드를 넣을 자리는 있지만, 렌더 코드가 읽지 않는다.**

- 카드(`js/data-cards.js`)에는 이미 `reviewed`, `nextReview`, `sources[].checked`가 있고, `js/cards.js:198`이 "마지막 확인 … · 다음 확인 …"을 그린다.
- 가이드 데이터(`ADHD_DATA`, `ADDICTION_DATA`, `FINANCE_DATA`, `BURNOUT_DATA`, `RELATIONSHIP_DATA`, `TRANSITION_DATA`, `POSTPARTUM_DATA`, `MENOPAUSE_DATA`, `EMOTION_GUIDE_DATA`, `SLEEP_DATA`, `GRIEF_DATA`, `ELDER_CARE_DATA`, `SENIOR_ISOLATION_DATA`, `INDEPENDENCE_DATA`, `MENTAL`, `BIRTH_DATA`, `DAD_DATA`, `ALONE_DATA`)는 모두 일반 객체 리터럴이라 필드를 더해도 기존 렌더는 무시한다. 다만 이번 작업 범위는 "문자열만"이라 필드는 추가하지 않았다.
- 렌더 쪽(`js/new-pages.js`, `js/render.js`)에는 검토일을 그리는 코드가 없다.

### 1) 데이터 (각 가이드 객체 최상위)

```js
review: {
  reviewed: '2026-09-27',
  next: '2026-12-27',
  sources: [
    { name: '국가정신건강정보포털 · 우울증', url: 'https://www.mentalhealth.go.kr/…', checked: '2026-09-27' },
    { name: 'NHS · Clinical depression', url: 'https://www.nhs.uk/mental-health/conditions/depression-in-adults/', checked: '2026-09-27' }
  ]
}
```

- 상황별로 나뉜 가이드(`EMOTION_GUIDE_DATA`, `SLEEP_DATA`, `GRIEF_DATA`, `RELATIONSHIP_DATA`, `TRANSITION_DATA`, `ELDER_CARE_DATA`)는 페이지 단위 `review` 하나에 둔다. 상황마다 다르게 둘 필요가 생기면 상황 객체에 같은 모양으로 덮어쓴다.
- `render.js`의 `getData(months)` 시기별 데이터와 `MENTAL`은 키마다 두지 말고 파일 상단 상수 하나(`STAGE_REVIEW`)로 둔다.

### 2) 렌더 (new-pages.js에 헬퍼 1개)

```js
function _guideReview(r) {
  if (!r || !r.reviewed) return '';
  return '<p class="bc-dates">검토일 ' + esc(r.reviewed) + ' · 다음 검토 ' + esc(r.next)
    + ' · 진료를 대체하지 않아요</p>'
    + (r.sources && r.sources.length ? '<ul class="bc-src" role="list">' + r.sources.map(function (s) {
        return '<li><a href="' + esc(s.url) + '" target="_blank" rel="noopener">' + esc(s.name) + '</a></li>';
      }).join('') + '</ul>' : '');
}
```

- 호출 위치: `initAdhdPage`, `initAddictionPage`, `initFinancePage`, `renderBurnoutPage`, `renderPostpartumPage`, `renderMenopausePage`, `renderWorkplacePage`, `renderRelationPage`, `renderTransitionPage`, `renderEmotionPage`, `renderSleepPage`, `renderGriefPage`, `renderElderPage`, `initIndependencePage`, `renderSeniorPage`의 마지막(도움 연결 칸 바로 위). `render.js`에서는 `render(d, months)`, `renderMentalPageContent`, `initBirth`, `renderDadContent`.
- 스타일은 카드의 `.bc-dates`·`.bc-src`를 재사용해 새 CSS 없이 시작할 수 있다. 색은 기존 CSS 변수만 쓴다.

### 3) 테스트 (tests/integrity.test.js)

- 위 가이드 객체마다 `review.reviewed`, `review.next`가 `YYYY-MM-DD`이고 `next > reviewed`인지
- 오늘 날짜가 `next`를 넘으면 실패 (검토 만료 경보)
- `sources`가 2개 이상이고 `url`이 `https://`로 시작하는지 (카드 규칙과 같게)
